# Billiqo POS Professional

A clean, professional starter for a modern retail POS system built with Python and Tkinter.

## Features
- Professional dark-blue dashboard theme
- Login screen with brand header and status feedback
- Sidebar navigation
- Dashboard cards for sales, inventory, customers, and payments
- POS billing screen with cart and totals
- Inventory management screen with search and product list
- Reports screen with summary metrics
- Responsive, card-based layout

## Run

```bash
pip install -r requirements.txt
python app.py
```

## Notes
- This is a professional UI starter and feature foundation.
- It is designed to be extended with real database and billing logic.
- The code is organized into small, reusable modules for easy maintenance.
